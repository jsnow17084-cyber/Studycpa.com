CPA Study Hub
A single-page, responsive study dashboard for the U.S. CPA Exam.
Includes:
Dashboard with section progress
AUD/FAR/REG Core and BAR/ISC/TCP Discipline sections
Practice quiz with explanations
Flashcards
Pomodoro-style study timer
Weekly study planner saved in browser localStorage
Responsive mobile layout
The curriculum labels are based on the current CPA Exam structure described by AICPA/CIMA. This is an independent study tool and is not affiliated with or endorsed by AICPA, NASBA, or any state board.
